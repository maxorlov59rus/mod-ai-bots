mod-ai-bots

Модуль AI-ботов для AzerothCore (3.3.5a). Боты — полноценные персонажи-игроки: следуют за владельцем, сражаются, используют заклинания, лечатся, баффуются, отступают при низком здоровье и общаются в чате. У каждого бота свой характер, внешность и экипировка.

AzerothCore 3.3.5a C++ GPL-2.0 AC-modules

Возможности

🤖 Боты игрока

Команды .bot add / remove / list / follow, следование за владельцем, бой рядом с ним, автоспавн при логине, синхронизация уровня.

🌍 Автономные боты в мире

Спавн при старте сервера (3 режима точек), самостоятельный поиск мобов, PvP между фракциями, респавн после смерти.

🎭 Индивидуальность

5 личностей с репликами (Aggressive, Calm, Jester, Grump, Hero), случайная внешность, экипировка по классу, ~21 000 комбинаций имён.

Живой мир

  • Группы ботов — боты одной фракции объединяются, лидер координирует атаку, лекари лечат товарищей
  • Социализация и дуэли — приветствия, угрозы и короткие честные бои 1v1 между фракциями
  • Боты-торговцы — покупка предметов у ботов за игровое золото
  • Территории — точки спавна принадлежат фракциям и периодически переходят из рук в руки
  • Гильдии ботов — отдельные для Альянса и Орды: уровни 1–25, XP, казна, гильдейские перки
  • Осады городов — отряды ботов штурмуют вражеские столицы
  • Питомцы — охотники призывают зверей, чернокнижники — демонов
  • Лут — боты собирают золото с убитых мобов в виртуальный кошелёк

Установка

1. Клонирование модуля

cd azerothcore-wotlk/modules
git clone <url-репозитория> mod-ai-bots

2. Сборка

cd azerothcore-wotlk
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=$HOME/ac-server
make -j$(nproc) && make install

3. SQL

mysql -u root -p acore_world < modules/mod-ai-bots/data/sql/db-world/mod_ai_bots.sql

4. Конфигурация

cp modules/mod-ai-bots/conf/mod_ai_bots.conf.dist $HOME/ac-server/etc/mod_ai_bots.conf

mod-ai-bots

AI bots module for AzerothCore (3.3.5a). Bots are fully-fledged player characters: they follow their owner, fight, cast class spells, heal, buff up, flee at low health and chat. Each bot has its own personality, appearance and gear.

AzerothCore 3.3.5a C++ GPL-2.0 AC-modules

Features

🤖 Player bots

.bot add / remove / list / follow commands, following the owner, fighting alongside them, auto-spawn on login, level sync.

🌍 Autonomous world bots

Spawn at server startup (3 spawn-point modes), find mobs on their own, faction PvP, respawn after death.

🎭 Individuality

5 personalities with chat lines (Aggressive, Calm, Jester, Grump, Hero), random appearance, class gear, ~21,000 name combinations.

Living world

  • Bot groups — same-faction bots team up: the leader coordinates attacks, healers tend to the wounded
  • Social behavior & duels — greetings, threats and short fair 1v1 fights between factions
  • Bot vendors — players buy items from bots for in-game gold
  • Territories — spawn points belong to factions and periodically change hands
  • Bot guilds — separate for Alliance and Horde: levels 1–25, XP, vault, guild perks
  • City sieges — bot squads storm enemy capitals
  • Pets — hunters summon beasts, warlocks summon demons
  • Loot — bots collect gold from killed mobs into a virtual wallet

2. Build

cd azerothcore-wotlk
